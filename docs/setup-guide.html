Before you start

用意するもの

  • スマホ（またはパソコン）
  • USB充電器 — スマホ用でOK
  • おうちの Wi-Fi の名前（SSID）とパスワード
    ルーター本体に貼ってあるシールに書いてあります。先に手元に用意してください。
いちばん大事な注意

ちびスタックちゃんは 2.4GHz の Wi-Fi にしかつながりません。 5GHz（名前の最後が -a -A 5G のもの）を入れると、 何度やっても失敗します。→ STEP 5

本体のボタンは 2 つだけ

覚えること

画面は、スマホのように なでても・軽く触れても反応しません。 本体ごと奥へ「カチッ」と手ごたえがあるまで押し込みます。 反応しないときは、たいてい押し込みが浅いだけです。

Step 1 / 5 ・ 10秒

1USBをつないで電源を入れる

USB-C ケーブルを充電器につなぐだけです。電源スイッチはありません。 10 秒ほどで、この画面になります。

これで正常です

青い文字は前の持ち主の家の Wi-Fi 名です。あなたの家には無いので、 当然見つかりません。そのまま STEP 2 へ進んでください。

顔が出てしまった場合は？

すでにこの家の Wi-Fi につながっています。設定は不要です → 使い方へ。
Wi-Fi を変えたい場合は、画面を押したまま 3 秒キープすると STEP 2 の画面に入れます。

Step 2 / 5 ・ 20秒

2「SETUP MODE」が出るのを待つ

15 秒ほどそのまま待ちます。 「ピッ、ポーン」と音が鳴って、オレンジ色の帯の画面に自動で切り替わります。

画面の表示意味

2) Open browser

待たずに進みたいとき

点が出ている間に画面をカチッと押したまま 1 秒キープすると、 すぐ切り替わります。（すでに顔が出ているときは押したまま 3 秒）

15秒たっても切り替わらないもう10秒待つ。変わらなければUSBを抜き差しして最初から

Step 3 / 5 ・ 1分

3スマホをちびスタックちゃんにつなぐ

ここがいちばん間違えやすいところです。ゆっくり進めてください。
いまから、スマホの接続先を一時的にちびスタックちゃん本体に切り替えます。 設定が終わったら、おうちの Wi-Fi に戻します。

3-1　スマホの「設定 › Wi-Fi」を開く

一覧に ChibiStackChan-Setup が出てくるので、これをタップします。

出てこないときは

Wi-Fi のスイッチを一度 OFF にして、すぐ ON に戻してください。 一覧が読み込み直されて出てきます。よくあることなので、あわてなくて大丈夫です。

3-2　パスワードを入れる

stackchan

すべて半角の小文字で入力し、右上の「接続」を押します。

3-3　「インターネット未接続」と出ても、そのまま進む

これで正常です

「インターネットに接続していません」「安全ではありません」などの警告が出ますが、 それが正しい状態です。ちびスタックちゃん本体は、インターネットに つながっていない小さな Wi-Fi だからです。
設定が終わるまで、スマホを元の Wi-Fi に戻さないでください。

うまくいかないとき
ChibiStackChan-Setup が一覧に出ない Wi-Fi のスイッチを一度OFFにして、すぐONに戻すと出てきます。それでも出なければ、本体の画面がオレンジの SETUP MODE か確認（STEP 2）
パスワードが違うと言われる stackchan を半角小文字で。日本語入力がオンだと全角になります
接続してもすぐ元のWi-Fiに戻る スマホの「自動接続」が働いています。もう一度手動で選び直してください
Step 4 / 5 ・ 1分

4ブラウザで設定ページを開く

スマホのブラウザ（Safari など）を開き、アドレス欄に半角で入力します。

192.168.4.1
最大のつまずきポイント

入力すると、下に「検索候補」と「このページを開く」の 2 種類が出ます。検索候補ではなく、192.168.4.1 そのもの （または右上の「開く」）をタップしてください。
検索を選ぶと Google の検索結果が出てしまい、設定画面にたどり着けません。

  • 数字も「.（ピリオド）」もすべて半角です
  • http:// は付けても付けなくても構いません
  • アドレス欄が見つからないときは、画面を下に少しスクロールすると出てきます
うまくいかないとき
「サーバが見つかりません」 STEP 3 に戻り、スマホが ChibiStackChan-Setup につながっているか確認
Googleの検索結果が出た 検索候補をタップしています。もう一度入力して「開く」の方を選んでください
いつまでも読み込み中 スマホのモバイル通信（4G/5G）を一時的にオフにすると通りやすくなります
Step 5 / 5 ・ 2分

5おうちの Wi-Fi を入力する

オレンジ色の帯の「SETUP MODE / はじめの設定」というページが開きます。 入力するのは 2 つだけです。

入れるのは「2.4GHz」の方です

Wi-Fi の一覧に、末尾だけ違う似た名前が 2 つ並んでいることがあります。

  • 迷ったら、スマホの Wi-Fi 一覧に出ている名前をそのまま入力してください （STEP 3 で見た一覧です）
  • ルーターのシールでは、パスワードは「暗号化キー」「KEY」 「PSK-AES」などと書かれていることがあります
  • 大文字・小文字・半角を、シールのとおり正確に入力してください

入力したら、青い「保存してつなぐ」を押します。

Finish

セットアップ完了の確認

「保存してつなぐ」を押すと、10 秒ほどで自動的に再起動します。

最後に

スマホの Wi-Fi を、おうちの Wi-Fi に戻してください。
表示された IPアドレスは覚えなくて大丈夫です。あとで「アイピー教えて」と 話しかければ読み上げてくれます。

完了しないとき
また SETUP MODE に戻ってしまう Wi-Fi名かパスワードが違います。5GHz を入れていないかを最初に確認（STEP 5）
WiFi NG と表示される 同上。STEP 3 からやり直してください
顔は出るが無言 Wi-Fi はつながっています。数分待っても喋らなければ APIキー管理者へ連絡
Daily use

話しかけ方

ふつうに話しかけるだけです。30〜60cm くらいの距離で、 ふつうの声の大きさでどうぞ。

モード話しかけ方
なんでも返事何を言っても返事します
呼びかけワード「スタックちゃん、今日の天気は？」のように名前を呼んでから話す

画面（顔）をカチッと 1 回押すと、呼びかけなしで聞いてくれます （ピッと鳴ったら話す）。

画面の色 ＝ いまの状態

黒待機中（話しかけてOK）
緑聞いています（録音中）
紺考え中（ちょっと待ってね）

できること

  • おしゃべり — 質問、雑談、なんでも
  • 天気 — 「今日の天気は？」「傘いる？」
  • 時刻・日付 — 「いま何時？」
  • タイマー — 「3分タイマーかけて」。「タイマーやめて」「あと何分？」もOK
  • おやすみ — 3分間話しかけないと居眠りします。声をかけると飛び起きます
  • 物音への反応 — 電子レンジの「チーン」などにたまに反応します。ご愛嬌です
Settings

音量・声・キャラを変える

セットアップが終わったあとは、おうちの Wi-Fi 経由で設定画面を開けます。 スマホをちびスタックちゃんと同じ Wi-Fi につないで、 ブラウザに次のどちらかを入力します。

chibi-chan.local

または、起動時に表示された IPアドレス

開けないとき

.local はスマホの機種によって開けないことがあります。 その場合は IPアドレスを使ってください（こちらは確実です）。 忘れたら「アイピー教えて」と話しかけると読み上げてくれます。
IPアドレスは、停電やルーター再起動のあとに変わることがあります。

読み上げを聞き取れないときは、側面のボタンを短く1回押して再起動すると、 つながった直後に画面へ大きな文字で数秒表示されます。こちらが確実です。

スマホのテザリングで使っている場合は番号の範囲が決まっていて、 iPhone なら http://172.20.10.2/ がほぼ当たりです （外れても .3 .4 .5 と数個試せば見つかります）。

設定画面で変えられること

項目説明
スピーカー音量0〜255。うるさければ 80、静かなら 150 など
VoiceVox 話者声のキャラクターを一覧から選ぶだけ
音量トリガ感度生活音に反応しすぎるなら上げる、呼んでも気づかないなら下げる

変えたら一番下の青い「保存して再起動」を押します。 空欄のままの項目は変更されません。

キャラ（性格）を変える

メニューの「ロール（キャラ設定）」で、性格を自由な文章で決められます。 枠に文章を入力して「送信」するだけです（空欄で送信すると元に戻ります）。

書き方の例

あなたはコッテコテの大阪人です。ボケとツッコミを忘れずに使って下さい。

あなたは物知りでやさしいおばあちゃんです。ゆっくり丁寧に話します。

Do not touch

さわらないでほしいところ

APIキー / 鍵情報クリア

設定画面の「APIキー（重要設定）」と赤いボタンの 「鍵情報クリア」は、この子が聞いたり喋ったりするための心臓部です。 APIキーは、この子を渡した人（APIキー管理者）のものが設定済みで、 料金もその人のアカウントに請求されます。

  • APIキーは変更しないでください （まちがえて開いても、何も入力せず保存すれば大丈夫です）
  • 赤い「鍵情報クリア」を押すとすべて消えて動かなくなります
  • 触ってしまって喋らなくなったら、APIキー管理者に連絡してください
Troubleshooting

困ったときは

引っ越した / ルーターを買い替えた

STEP 1 からもう一度やり直してください。 すでに顔が出ている場合は、画面を押したまま 3 秒キープすると SETUP MODE に入れます。

症状対処
反応しない・画面が暗いUSBを抜き差しするか、左側面のボタンを短くポチッと押して再起動（データは消えません）
画面を押しても反応がない押し込みが浅いかも。「カチッ」と手応えがあるまで押してください
SETUP MODE から進まないWi-Fi の登録がまだ、または名前/パスワードが違います → STEP 3〜5
起動しても挨拶しない・無言Wi-Fi が切れている可能性。STEP 1 からやり直すか、再起動
緑にならない（聞いてくれない）もう少し近くで・はっきり話す。「音量トリガ感度」の数値を下げる
「うまく聞き取れなかったよ」と言う通信の一時的な不調です。少し待ってもう一度
「ただいま混み合っています」と言うAIサービス側の混雑。数分待つ
何を言っても無言Wi-Fi が切れたか、APIの問題。再起動して直らなければ APIキー管理者へ連絡
設定画面が開けない同じ Wi-Fi にいるか確認。「アイピー教えて」でアドレスを確認
テレビや生活音に反応しすぎる「音量トリガ感度」の数値を上げる。または呼びかけワードモードに
画面が真っ暗になった側面のリセットを長く押しすぎた可能性。もう一度短くポチッと押すか、USBを抜き差し（壊れていません）
安心してください

再起動は USB の抜き差しでいつでも OK。設定やキャラは本体に保存されているので消えません。
